# 界面约定

EggplantChat 使用微信、QQ 式桌面聊天布局。左侧依次是导航栏、设备会话列表，右侧是消息记录和编辑区。

- 组件库使用 `shadcn_ui`。按钮、输入框、对话框、提示、徽标和进度条使用库组件。
- 图标使用库导出的 Lucide。产品不使用茄子相关视觉元素。
- 主题使用 Zinc 中性色，默认跟随系统，支持手动切换明暗。
- 导航栏宽 64，会话列表宽 280，初始窗口为 1180 × 800，最小窗口为 820 × 620。
- 阅读字号为 14，行高为 1.65。中文回退字体使用系统的 PingFang SC、Microsoft YaHei。
- 圆角以 12 为主，布局、阅读样式和尺寸集中在 `lib/app_theme.dart`。
- 富文本编辑和显示使用 Flutter Quill。格式工具栏使用 shadcn 按钮，不重新实现编辑器。
- Enter 发送，Shift + Enter 换行，保留中文输入法的回车确认行为。
- 图片和附件先进入待发送区。只有点击发送或发送快捷键才开始传输。
- 消息区显示真实消息和传输状态，不填充示例设备或假聊天。
- 附近设备点击即可连接；固定 IP 只需输入地址和端口，不使用配对码或限时配对窗口。连接信息自动保存，应用启动后自动重连。
